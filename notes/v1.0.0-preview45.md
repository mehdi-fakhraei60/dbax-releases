## Bax 1.0.0 preview 45 (جریان مرحله‌ای انتخاب مبدأ و مقصد)

### تغییرات نسخه ۴۵:
- **بدون پیش‌فرض**: موقع شروع سفارش، هیچ مبدأ یا مقصدی از قبل پر نمی‌شود؛ فقط «مبدأ» نمایش داده می‌شود.
- **انتخاب مبدأ** به سه روش: ضربه روی نقشه (سوزن ثابت)، «موقعیت من» (GPS با آدرس معکوس)، یا از ذخیره‌شده‌ها.
- **بعد از انتخاب مبدأ**: فرم اطلاعات فرستنده (جدید / تأیید ذخیره‌شده / «خودم») و بعد از تأیید، «مقصد» تازه نمایش داده می‌شود.
- **تا قبل از تأیید فرستنده، مقصد به‌کلی مخفی است**.
- بعد از انتخاب مقصد و تأیید گیرنده، مراحل بعدی (کالا → قیمت → ثبت سفارش) ادامه پیدا می‌کند.
